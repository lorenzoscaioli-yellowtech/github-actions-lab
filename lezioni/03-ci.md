# Lezione 03 - Continuous Integration

File: `.github/workflows/03-ci.yml` · App: `app/`

## Cosa dimostra

- Il pattern base di ogni CI: checkout → setup runtime → installa → testa.
- `actions/setup-node` con `cache: npm`: la cache si basa sull'hash del
  lockfile, quindi al secondo run `npm ci` è molto più veloce.
- `npm ci` invece di `npm install`: installa esattamente il lockfile.
- `defaults.run.working-directory` per non ripetere `cd app`.
- `permissions: contents: read`: il token ha solo ciò che serve.
- `actions/upload-artifact`: la build e l'output dei test sopravvivono al
  runner e si scaricano dal run.

## Come lanciarla

```bash
gh workflow run 03-ci.yml && gh run watch
gh run download --name build-e-report -D /tmp/ci   # scarica l'artefatto
```

Oppure toccare qualcosa in `app/` e fare push o aprire una PR.

## Cosa osservare nei log

1. Step setup-node: la prima volta "Cache not found", dalla seconda
   "Cache restored from key: ...".
2. Il riepilogo del run mostra `pass 3 / fail 0`.
3. In fondo alla pagina del run compare l'artefatto `build-e-report`.

## Da provare

- Rompere un test (`assert.equal(somma(2, 3), 6)`) e aprire una PR: il check
  diventa rosso e blocca il merge se il branch è protetto.

## Note dopo l'esecuzione

Primo run (29/09/2026) FALLITO, e la causa è la lezione più utile del giorno:

- `node --test test/` con una directory funziona su Node 26 (locale) ma non su
  Node 22 (runner): i test non partivano affatto. Corretto con il glob
  `"test/**/*.test.js"`. Morale: la versione in `setup-node` deve essere
  quella con cui si sviluppa, o la CI deve testare più versioni (lezione 08).
- Lo step "Test" era comunque VERDE: `npm test | tee file` restituisce
  l'exit code di `tee`. La shell di default è `bash -e`, senza `pipefail`.
  Con `shell: bash` esplicito GitHub usa `bash -e -o pipefail`. Aggiunto in
  `defaults.run`.
- Senza terminale node:test usa il reporter TAP: forzato `--test-reporter=spec`
  in package.json così il grep del riepilogo trova le righe `ℹ pass`.

Secondo run: `Cache hit` in setup-node, `pass 3 / fail 0`, artefatto caricato.
L'artefatto si scarica con `gh run download <id> --name build-e-report`.

Aggiornamento dopo la lezione 08: anche il glob `"test/**/*.test.js"` non
funziona su Node 20. Lo script ora è `node --test --test-reporter=spec`
senza argomenti, e Node trova i test da solo. Dalla lezione 10 setup-node e
`npm ci` stanno nella composite action `setup-app`.
